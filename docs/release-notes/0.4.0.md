**干净出口不再写死单个节点：HY2 池整池挂掉时自动退到台湾入口；新增站点健康守卫与 7890 收口规则。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/AX3000TOpenwrt/issues/new/choose) 反馈 —— 带上设备型号、固件版本与相关日志。

## 本版内容

**守护**

- 调整 干净出口 —— 每轮只解析一次：当前入口在候选里且可达就保持不动，否则按 `HY2 ×3 → 台湾-优化3 → 台湾-优化2-GPT` 取第一个可达的；2.1 / 2.3 / 3.6 共用同一个结果，不再每 5 分钟互切。
- 新增 退避 —— 候选全部不可达时 10 分钟内不重复扫描，整池挂掉时不再每轮空转 40 秒。
- 调整 探针 —— 干净出口只服务 Google，探针从 GitHub 改为 `generate_204`；GitHub 全族已拆到 `🔗 GitHub 出口` 组（分流规则仓）。
- 修复 劣化判定 —— 两次探测取较慢那次，不再把结果多除 2（此前阈值被系统性抬高约一倍）；`10.0` / `12.5` 这类耗时不再漏判。
- 新增 站点健康守卫 `dest-guard.sh` —— 按「站点 → 策略组」用真实 URL 探测（X / GitHub / B站 / YouTube / 通用），默认 dry-run 只写日志。

**防火墙**

- 新增 `mixedport.nft` —— 拦住 LAN 到 7890 的直连（IPv4 按网段、IPv6 按 `br-lan` 入接口），路由器自身与透明代理不受影响；开机会自动加载。

**恢复**

- 修复 `recover-now.sh` 的 `check` 模式 —— 只诊断，不再改 fake-ip 过滤文件。
- 修复 `fix-router.sh` —— 路由器不可达或 SSH 失败时直接退出（并留在路由器 WiFi），不再把「一步没做成」显示成「跑完 4 步」。

**仓库**

- 新增 Issue 表单、贡献指南与安全说明。
