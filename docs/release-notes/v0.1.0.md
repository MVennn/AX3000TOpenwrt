**首版：把 AX3000T 的运维脚本与文档，整理成一个能独立看懂、能独立演进的仓库。**

## 本版内容

**文档**

- 新增 状态速查 —— 一页看完配置、访问入口与自检命令；值是参考快照，换设备需重新核对。
- 新增 硬件与固件基线 —— 型号、内核、内存、闪存、网络拓扑、无线，每条标来源与测点。
- 新增 排障手册 —— 八个高频现象（连上没网、DNS 全失败、代理离线、OOM、看门狗复位、tmpfs 写满、nft 表没加载、cron 被覆盖），每个配可直接粘贴的排查命令。
- 新增 保留策略 —— 备份区命名约定、修剪阈值、「改完即删」，以及一份不做什么清单。
- 新增 文档规则 —— 单一正本、链接纪律、变更触发矩阵、索引维护。
- 新增 凭据与安全须知 —— 只写凭据的存放位置，不写明文值，附轮换顺序。
- 新增 第三方声明 —— OpenWrt、ShellCrash、mihomo、MetaCubeX 规则集、art-design-pro 的来源与许可证。

**脚本**

- 调整 guardian.sh —— 网络守护移入 `guardian/`；只做「检测 + 最小化修复」，行为零变更。
- 调整 rc.local —— 开机脚本移入 `system/`；含 tmpfs 目录与 `/var` 运行时目录的兜底重建，行为零变更。
- 调整 recover-now.sh —— 恢复脚本移入 `recovery/`；一键完成「摘 DNS 劫持 → 停核心重生成 → 加载 nft 表 → 重载防火墙 → 恢复定时任务 → 连通性校验」，行为零变更。
- 调整 Windows 触发器 —— 双击即可把恢复脚本推到路由器上执行；移入 `recovery/local-tools/`，行为零变更。
- 调整 归档脚本 —— 一次性补丁与核心升级脚本移入各目录的 `archive/`；留着是为了留档，不是为了再跑。

**运维**

- 修复 7890 开放代理 —— 新增 nft 表 `inet mixedport` 收口，LAN 侧连不上、路由器自身照常、透明代理不受影响。
- 修复 出口漂移 —— AI 出口固定到经实测可用的节点，避免 url-test 漂到不可用地区。
- 调整 内存与闪存 —— 清理诊断残留后可用内存从 40.5 MB 升到 62 MB 以上；判断余量以 `df` 为准。

---

需要 OpenWrt 25.12.6 + ShellCrash；设备为小米 AX3000T（MT7981）。
脚本会直接改路由器状态，执行前请先看 [排障手册](../TROUBLESHOOTING.md)。
