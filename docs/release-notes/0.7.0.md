## 本版内容

**脚本**

- 新增 guardian/guardian.sh 流量归因 cron 自愈 —— /etc/ShellCrash/traffic-stats.sh 在、crontab 里那一行不在时自动补回并重载，日志写 FIX: restored traffic-stats cron line；脚本文件不存在时不补，避免每 5 分钟刷一条失败
- 修复 system/router-health/health-snapshot.sh 保留清单巡检 —— 回滚副本、隐藏临时件、禁用件与内核缓存不再算漏项，每 30 分钟的告警只在漏项集合变化时出现；同一块 512 KiB 日志缓冲的覆盖时长由约 3.8 小时回到约 6.5 天

**文档**

- 新增 docs/TROUBLESHOOTING.md「升完内核后重启验收空响应 / 规则回显晚到」 —— 排障手册由九个现象扩到十个，排查命令可直接粘
- 调整 README.md 部署段 —— 第 4 步补 guardian/memgate.sh 与 guardian/memgate.conf 的 scp 与 chmod，新增第 5 步 system/router-health/ 三个巡检脚本（tmp-watch.sh / health-snapshot.sh / backup-prune.sh）的落点与 cron
- 调整 README.md 目录树 —— 补 guardian 的 memgate、system 的四张自建 nft 表与 router-health、tools 的金库守卫、vault/ 私有金库，mihomo 一行补 CrashCore.upx
- 修复 AGENTS.md、docs/PITFALLS.md 的跨仓名 —— ZcodeAIModels 改为 ModelBus（原 ZcodeAIModels）
- 调整 docs/OPERATIONS.md、docs/DEPLOY.md、docs/TROUBLESHOOTING.md —— guardian 的 cron 行自愈写进「守护进程在做什么」表，部署职责与 cron 参考清单同步
- 调整 docs/README.md 索引 —— 补 release-notes 的 0.6.0 与 0.7.0 两行
- 修复 文档口径 —— 删除一次性清理分片与其引用，上游链接、LAN 占位符、私有历史镜像、凭据示例的写法统一；正文不再引用不入库的 .work/ 私有路径

**运维**

- 调整 设备 mihomo 内核 —— 由 v1.19.28 升到 v1.19.33（CrashCore.upx 15,007,192 B），运行态 /version 一致，自动更新不会再拉回旧版
