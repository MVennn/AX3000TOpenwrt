**运维版：守护进程补上干净出口自动切换与内存闸门，设备上在跑的东西全部收回仓库。**

## 本版内容

**脚本**

- 新增 干净出口自动切换 —— 当前入口连不上 GitHub 时，守护进程自动换到第一个可用入口并同步 `🤖 AI网页`；五个候选全挂时只告警、不乱切。
- 修复 内存闸门缺失 —— `guardian.sh` 在拉起 CrashCore 前先问 `memgate.sh`，内存不足就跳过本轮，避免「OOM → 拉起 → 再 OOM」的循环。
- 修复 台湾节点误判 —— 台湾-优化3 / 台湾-优化2-GPT 不再被当成「Google 判 CN」的坏节点。
- 修复 干净出口候选顺序 —— 从印度优先改为台湾优先、印度兜底，与设备上 2026-10-21 的实测一致。
- 新增 `guardian/memgate.sh` —— 内存闸门的源文件；此前只在路由器上，仓库里没有。
- 新增 `guardian/memgate.conf` —— 闸门阈值与连续放行次数。

**文档**

- 调整 部署映射 —— `docs/DEPLOY.md` 补上 `memgate.sh` / `memgate.conf` 的目标路径、调用方与回退方式。

---

需要 OpenWrt 25.12.6 + ShellCrash；设备为小米 AX3000T（MT7981）。
脚本会直接改路由器状态，执行前请先看 [排障手册](../TROUBLESHOOTING.md)。

---

> 风险提示：本仓库的脚本会直接修改路由器的系统状态（重启服务、重载防火墙、改 crontab、
> 切换代理策略组）；本仓库不保存凭据，脚本从环境变量或设备侧真源读取。执行前请确认已备份，
> 详见 [凭据与安全须知](../SECRETS.md)。
